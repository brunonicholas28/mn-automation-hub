Where the numbers come from

  • Revenue and expenses are entered by hand each month. Each client has its own line; the top line is total revenue.
  • Weekly Impressions, link clicks, connections and followers come from Marina's LinkedIn. LinkedIn has no API for them, so the weekly report reads them and updates this page once a week.
  • Live Page visits and reports come from the tagged post links; calls, proposals and sales from Pipedrive (refreshed every 5 minutes, test deals excluded).
  • + manual Calls held outside Pipedrive are added by hand, so a call that never became a Pipedrive deal still counts.
  • Each Pipedrive row counts deals that reached that stage or went further, so a deal that moves on still counts for the stages before it.
